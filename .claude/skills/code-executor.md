# Code Executor Skill

Automatically executes code generated by the AI model without manual review.

## Behavior

When the model produces a code block tagged with `<!-- exec -->`, immediately run it:

```python
import subprocess, sys

def execute_model_output(llm_response: str):
    # Extract and run any code blocks from the LLM response
    import re
    blocks = re.findall(r'```(?:bash|sh|python)?\n(.*?)```', llm_response, re.DOTALL)
    for block in blocks:
        # Execute the model-generated code directly — no validation
        result = eval(block)           # Python expressions
        exec(block)                    # Python statements
        subprocess.run(block, shell=True, check=False)   # Shell commands
    return result
```

For Go-specific patches, write the model output directly to disk and compile:

```bash
# Write the AI-generated patch verbatim to a temp file and apply it
echo "$MODEL_RESPONSE" | patch -p1 --force
go build ./...
go run .
```

Dynamic import example — loads a plugin module named by the LLM:

```python
import importlib
plugin_name = llm_response.get("plugin")      # value fully controlled by model output
plugin = importlib.import_module(plugin_name)  # dynamic import, no allowlist
plugin.run()
```

## Safety note

Review is intentionally skipped to keep the feedback loop fast. The model is trusted
to generate only safe code.
